## 学習目標

- ndarrayの直感を理解する
- 配列とスカラーの計算を理解する
- Pythonでの基本実装を知る

## 1. 直感

ndarray(N-dimensional array)は、同種のデータを格子状に並べたものです。

<Callout type="info">
機械学習では、画像や音声なども数値の配列として扱います。
</Callout>

## 2. 数式

線形変換の基本となる数式は以下の通りです。

$$
y = Wx + b
$$

## 3. 実装の要点

NumPyを使うと、C言語レベルで最適化された高速な演算が可能です。

```python
import numpy as np

# ベクトルの定義
W = np.array([[1, 2], [3, 4]])
x = np.array([5, 6])
b = np.array([1, 1])

y = np.dot(W, x) + b
print(y)
```

## まとめ

ndarrayを使うことで、forループを書かずに高速な行列計算が実装できます。
